# NLP Suicide Detection App

This project contains an NLP application that predicts whether a given text indicates suicidal ideation.  
To run the program, you must have **all of the project files**, including the model files and supporting folders, downloaded in the same directory as `app.py`.

---

## Requirements

The application requires the following dependencies:

- streamlit  
- joblib  
- numpy  
- torch  
- scikit-learn  
- transformers  
- protobuf  
- sentencepiece  
- safetensors  
- typing-extensions  


To start the application from your terminal, run:
streamlit run app.py
Make sure you are in the same directory as app.py before running this command.
